# 🎹 Keyboard Shortcuts Reference

Quick reference guide for keyboard navigation in Railroad Maintenance Simulator.

---

## General Navigation

| Shortcut | Action |
|----------|--------|
| `Tab` | Move to next element |
| `Shift` + `Tab` | Move to previous element |
| `Enter` | Activate button/link |
| `Space` | Toggle checkbox/button |
| `Esc` | Close dialogs/modals |
| `?` | Show help/shortcuts |

## Tips for Efficient Navigation

### 🎯 Quick Access
1. Press `Alt` + `0` to skip repetitive navigation
2. Use `Tab` to quickly jump between interactive elements
3. Press `?` anytime to see available shortcuts

### ♿ Accessibility Mode
1. Enable High Contrast: Sidebar → Accessibility → High Contrast Mode
2. Reduce Motion: Sidebar → Accessibility → Reduce Motion
3. Adjust Font Size: Sidebar → Accessibility → Font Size slider

### 📊 Working with Data
- Use `Tab` to navigate through data tables
- Press `Enter` on expandable sections
- Use arrow keys in chart legends
